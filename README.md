# apiclient

The Go client for [Hanzo Runtime](https://hanzo.ai) — sandboxes, snapshots, and
the toolbox that runs inside one.

```go
import "github.com/hanzoai/apiclient"
```

Generated from Runtime's OpenAPI document. Pure standard library: it requires
nothing else, so embedding it costs a caller nothing but this package.

Regenerated rather than edited — changes belong to the document it comes from.
